# Admin Dashboard

A modern, responsive admin dashboard built as part of the **Tailwind CSS v4 From Scratch Beginner To Pro** course on Udemy. This project demonstrates advanced web development techniques using **Tailwind CSS v4**, featuring a sidebar layout, dynamic charts, and responsive widgets for data visualization.

## ✨ Features
- **Responsive Sidebar**: Collapsible sidebar navigation that adapts to mobile and desktop screens.
- **Dashboard Layout**: Grid-based layout with a header, main content area, and widgets for key metrics.
- **Dynamic Charts**: Placeholder visualizations (mocked) for statistical data, styled with Tailwind CSS.
- **Widgets**: Card-based components displaying metrics, styled with shadows and rounded corners.
- **Responsive Design**: Optimized for various screen sizes using Tailwind’s breakpoint utilities.

## 🛠️ Technologies Used
- **HTML5**: Semantic markup for structure.
- **Tailwind CSS v4**: Utility-first CSS framework for styling.
- **JavaScript**: Basic interactivity (e.g., sidebar toggle).
- **Node.js & npm**: For Tailwind CSS setup and build process.

## 🚀 Getting Started

### Prerequisites
- **Node.js** and **npm** installed on your machine.
- A modern web browser (e.g., Chrome, Firefox).

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/maxim-francesco/admin-dashboard.git
   cd admin-dashboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Build Tailwind CSS**:
   ```bash
   npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
   ```

4. **Run the project**:
   - Open `index.html` in a browser, or use a local server (e.g., `npx serve` or VS Code Live Server).
